PowerSystemsClustering.jl reduces a [PowerSystems.jl](https://github.com/Sienna-Platform/PowerSystems.jl)
`System` into a [PowerSystemsInvestmentsPortfolios.jl](https://github.com/Sienna-Platform/PowerSystemsInvestmentsPortfolios.jl)
`Portfolio` for capacity expansion modeling with
[PowerSystemsInvestments.jl](https://github.com/Sienna-Platform/PowerSystemsInvestments.jl). It
selects representative periods for time sampling and aggregates individual units into
representative technologies.
